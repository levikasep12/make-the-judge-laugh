A single original one-liner written to make the judge laugh, generated by a tiny deterministic program: a joke built on the true, recognisable detail that a smartwatch counts your steps, and a surprising share of anyone's daily steps are just pacing around the house looking for a lost phone.

## Run it

```sh
python3 main.py
```

It writes one line of comedy (116 characters) to `/output/entry.txt`. Standard library only, no network, no input files, and the same bytes on every run from any working directory.
